# Серия пенальти в GPF-срезе — дизайн

**Дата:** 2026-10-29
**Статус:** к реализации (решения зафиксированы grilling-сессией 2026-10-29).

## Что делаем

Полноценную **серию пенальти** в GPF Gameplay Slice (11 на 11, оригинальный C++-рантайм
GameplayFootball `of_port` через GDExtension). Серия живёт **внутри C++-рантайма** (referee/match
слой); Godot-сторона (`gpf_slice.gd`) — только презентация: кружки-индикаторы, баннеры исходов,
fade-переходы, финальный экран. Это пункт 1 роадмапа вики `порт-gdextension.md` («Серия пенальти
для ничьей после 120:00»).

Legacy `match.tscn` и его одиночный пенальти (`penalty_controller.gd`) **не затрагиваются** —
спек Фазы C из `2026-07-15-penalty-design.md` относится к старому рантайму и реализовываться не
будет (пометить в вики).

## Контекст (факты, проверено по коду)

- **Одиночный пенальти уже работает в C++**: `debug_force_set_piece(6, team)` расставляет
  бьющего/вратаря/камеру; человек-бьющий: стрелки = прицел, D = удар с зарядом
  (`humancontroller.cpp:263-295`); вратарь-ИИ прыгает вслепую (`match.cpp:2430+
  CommitPenaltyDive`, `RandomDiveZone`); человек-вратарь выбирает зону стиком через
  `Match::GetDefenderStick` (`match.cpp:2401-2407`). Исход (гол/сейв/мимо) уже решает C++.
- **Серии нет нигде**: при ничьей после 2-го доп. времени referee ставит фазу
  `e_MatchPhase_Penalties` и сразу вызывает `GameOver()` (`referee.cpp:141`, `:233-249`).
  Grep по `src/` чекаута: `shootout|PenaltyShootout|penalty_series` — ничего.
- **Клипы эмоций существуют** в данных оригинала: `celebration/happy_normal`,
  `celebration/happy_extreme`, `celebration/sad_normal`. Срез стримит любую позу, которую играет
  C++ (`get_player_pose → anim/frame/bones`) — клипы доступны без пересборки ассетов.
- **GDScript не может двигать игроков** — только мяч (`debug_set_ball`) и выбор бьющего
  (`request_set_piece_taker(id)`). Вся расстановка/последовательность обязана жить в C++.
- Снапшот матча: `get_snapshot()` (`gpf_runtime_node.cpp:670-758`) — есть
  `in_set_piece/set_piece_type/set_piece_role/goal_scored/ball_in_goal/last_goal_team/game_over/
  match_phase` и др. Новые поля серии добавляются туда же.
- Расширение рантайма — прецедент: локальные коммиты чекаута `3b42ef9` (часы презентации) и
  `da1d99f` (камера презентации) поверх `of_port`.

## Правила серии

- **Формат**: по 5 ударов на команду с чередованием (A,B,A,B,…). **Ранний стоп**, когда
  отставание математически не отыгрывается (напр. 3:0 после трёх ударов команды A). При равенстве
  после 5+5 — **sudden death парами**: пара ударов = раунд; первый раунд с разными исходами
  (одна забила, другая нет) завершает серию в пользу забившей; оба забили/оба не забили — раунд
  ничейный, следующий. Ничьей быть не может.
- **Первый бьющий** — случайная «монетка» при входе в серию (детерминированно по сиду матча,
  воспроизводимо для отладки). Жребий отдельно не показывается.
- **Ворота** — одни на всю серию, выбираются **случайно** при входе в серию.
- **Очередь бьющих** = игроки команды, **отсортированные по навыку исполнения пенальти** (тот же
  атрибут/логика, по которой уже вычисляется штатный пенальтист). Первые 5 ударов — топ-5 списка.
  Sudden death продолжает список с 6-го и далее по кругу. Вратарь команды участвует в списке на
  общих основаниях (на его ударе ворота пусты — это нормально, защищает вратарь соперника).
  Настраиваемая очередь — будущая фича, не в этом спеке.
- Пока бьёт игрок команды A — ворота защищает вратарь команды B, и наоборот.

## Роли человека

- **Свои удары** — человек бьёт за очередь своей команды: стрелки = прицел, D = удар с зарядом
  (переиспользуем штатный путь одиночного пенальти). Бьющий = игрок очереди; управление на него
  переключается автоматически.
- **Чужие удары** — человек управляет **вратарём**: стик = зона прыжка (как в текущем
  K-режиме среза, `GetDefenderStick`), стик в нейтрали на момент удара = прыжок по центру; шаги
  по линии — как сейчас.
- Смена роли по ходу серии автоматическая и невидимая (без смены HUD-контролов сверх договорённых).

## Исход удара (классифицирует C++)

- **Гол** — существующая проверка взятия ворот.
- **Сейв** — вратарь поймал/отбил, мяч не в воротах.
- **Мимо** — мяч ушёл за пределы/мёртв (штанга, мимо рамки, отскок назад без взятия).
- **Страховочный таймаут ~3с** — мяч завис в неопределённом состоянии (застрял, нестабильный
  отскок) → считается «мимо», серия идёт дальше. Зависание серии невозможно.
- Исход выставляется в снапшот как событие на текущий удар (`goal/save/miss` + id бьющего),
  GDScript только рисует.

## Эмоции и тайминги

**Обычный удар серии:**

- **Гол** — без анимации празднования: баннер GOAL ~1.2с → fade → следующий удар.
- **Сейв** — баннер SAVE ~1.2с + бьющий грустит (`sad_normal` ~2с) → fade.
- **Мимо** — баннер MISS ~1.2с + бьющий грустит (`sad_normal` ~2с) → fade.
- Вратарь рядовые сейвы не празднует; рядовые голы команда не празднует.

**Решающий удар** (математическая победа серии):

- **Решающий гол** — бьющий играет `happy_extreme`, далее штатное празднование **5с** (без
  extended replay).
- **Решающий промах соперника** — вратарь играет `happy_normal`, штатное празднование 5с.
- После празднования — финальный баннер «Победа: X:Y» (3с) → `get_tree().quit()` (рантайм
  одноразовый, возврата в матч нет).

**Fade между ударами:** в чёрное 0.3с → чёрный кадр 0.15с (вся перестановка акторов/мяча/камеры
происходит под прикрытием) → обратно 0.3с → фаза прицела нового удара. Видимых телепортов нет.
Fade — Godot-оверлей (`CanvasLayer` + `ColorRect`), поверх картинки из C++.

## Подавление матчевых систем на время серии

- Счёт и время матча **заморожены** (счёт серии — отдельный, на кружках).
- После гола в серии **нет кик-оффа** — переход к следующему удару.
- Extended replay (`sig_OnExtendedReplayMoment` → `replay_moment`) в серии **не эмитится**.
- Все полевые, не участвующие в текущем ударе (включая ждущих бьющих), стоят **замороженными на
  центральной линии**.
- Ранний `step_one_tick`-форс-энд матча при переходе в доп. время на серию не влияет (серия
  запускается после штатного `GameOver`-пути на ничьей либо по F3 из любого состояния).

## HUD (Godot, `gpf_slice.gd`)

- **Сверху** ряд кружков домашней команды, **снизу** — гостевой. Заполнение слева направо по
  порядку ударов: зелёный = забил, красный = не забил, серый = ещё не бил. **Цифр счёта и номера
  раунда нет** (только кружки).
- **Баннер исхода** GOAL/SAVE/MISS ~1.2с по центру (тот же слой, что ReplayBanner).
- **Финальный баннер** «Победа: X:Y» крупно по центру, 3с → закрытие игры.
- Во время серии матчевые счёт/время в HUD скрыты.

## Архитектура

**C++ (внешний чекаут `GameplayFootball-of_port`):**

- `src/onthepitch/referee.cpp` (+ `match.cpp`, `gamedefines.hpp`): состояние серии
  (`e_MatchPhase_Penalties` продлевается реальной серией вместо немедленного `GameOver()`),
  вход `debug_force_shootout()` и авто-вход при ничьей после 120', чередование, монетка, выбор
  ворот, очередь по навыку, ранний стоп/sudden death, классификация исхода + таймаут 3с,
  эмоции-клипы, подавления из раздела выше.
- Всё переиспользует штатные механики одиночного пенальти (расстановка, прицел, заряд,
  `CommitPenaltyDive`, `GetDefenderStick`) — серия лишь оркеструет их в цикл.

**GDExtension (`gdextension/src/gpf_runtime_node.cpp`):**

- Биндинг `debug_force_shootout()`.
- Новые поля `get_snapshot()`: `shootout_active`, `shootout_round`, `shootout_score0/1`,
  `shootout_kicks0/kicks1` (по 5 исходов: 0=не бил, 1=забил, 2=не забил — для кружков),
  `shootout_event` (событие последнего исхода: `goal/save/miss` + `kicker_id`),
  `shootout_decisive` (флаг решающего удара), `shootout_winner` (-1 пока не решено),
  `shootout_celebrating` (идёт празднование решающего) — чтобы Godot знал, когда баннер/quit.

**GDScript (`scripts/match/gpf_slice.gd`):**

- Клавиша **F3** → `runtime.debug_force_shootout()` (во время активной серии игнорируется;
  вход — из любого состояния матча).
- По снапшоту: кружки, баннеры исходов, fade-оверлей, финальный баннер + `get_tree().quit()`.
- Смена «бьющий/вратарь» для человека — полностью на стороне C++ (Godot ничего не переключает).

## Триггеры

- **F3** — debug-запуск серии в любой момент матча.
- **Авто** — ничья после 120' (в `referee.cpp` вместо текущего `GameOver()` на ничьей).

## Тестирование

- Headless-тест `tests/check_gpf_shootout.gd` по образцу `check_gpf_setpieces.gd` /
  `check_gpf_full_match.gd`: форс-серия по F3-пути, драйв симуляции (`step_fixed` / короткий
  `match_duration`), проверка: серия активна, удары чередуются, исходы классифицируются
  (форс-гол через `debug_set_ball`), счёт растёт, ранний стоп и sudden death завершают серию,
  `shootout_winner` выставляется, повторных кик-оффов нет.
- Ручная приёмка (рендер/фил): F3, кружки, баннеры, fade, эмоции, финальный экран → quit.
