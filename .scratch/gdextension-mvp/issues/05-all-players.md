# 05: Все 22 игрока

**What to build:** 22 CPU-skinned игрока на поле — каждый `MeshInstance3D`, вертексы из C++. `AnimCollection` работает на всех (293 `.anim`, выбор клипа по `CrudeSelection` + sort-chain). Игроки бегут, анимируются, переключают клипы по скорости и направлению. На экране — полный состав обеих команд (11 синих + 11 красных).

**Blocked by:** 03 (CPU-skinning pipeline), 04 (один управляемый игрок)

**Status:** superseded — новая карта: [Перенос GameplayFootball в Godot](../../godot-port/map.md)

- [ ] 22 игрока — 22 `MeshInstance3D`, все вертексы из C++

- [ ] Игроки бегут, анимируются, переключают клипы
