# 07: Верификация — SHA-1 детерминизм

**What to build:** `tools/determinism` — headless прогон матча (Human vs AI, фиксированный сценарий ввода). SHA-1 хеш состояния игры (позиции игроков, мяча, анимации) совпадает с оригиналом (патченная ветка `oracle` форка `GameplayFootball`). Доказательство: геймплей тик-в-тик идентичен оригиналу.

**Blocked by:** 06 (AI + полный матч)

**Status:** superseded — новая карта: [Перенос GameplayFootball в Godot](../../godot-port/map.md)

- [ ] `tools/determinism` — headless прогон матча (без рендера, только sim)
- [ ] Фиксированный сценарий ввода (как в оракуле C#-порта: `seed`, `ticks`, `dir`, `buttons`)
- [ ] SHA-1 хеш состояния (позиции, анимации, мяч) совпадает с оригиналом
- [ ] RNG: все вызовы `random(` идут через `boostrandom()`, сид из сценария
- [ ] Put-фаза пиннится к тику (как в оригинале — иначе физика мяча невоспроизводима)
- [ ] Код возврата 0 = совпадение, 1 = расхождение, 2 = ошибка входа
