# 09: Скаутинг

**What to build:** Полный скаутинг-хаб прототипа: скауты, карта регионов, назначение заданий,
отчёты о найденных игроках, сети скаутов и действия с ними. Логика (регионы, рейтинги, найденные
игроки, сроки, вероятности) переносится 1:1; всё сохраняется в карьере.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Экран скаутинга: сетка скаутов, карта/панель региона, карточка скаута, отчёты, как в прототипе.
- [ ] Создание/редактирование задания, отправка скаута, завершение и возврат отчёта работают по правилам прототипа.
- [ ] Найденные игроки и сети сохраняются; действия (нанять/уволить/перераспределить) совпадают.
- [ ] Отчёты открывают игрока и позволяют перейти к трансферу.
- [ ] Golden-тест скаутинга с фиксированным seed; сейв восстанавливает состояние.
