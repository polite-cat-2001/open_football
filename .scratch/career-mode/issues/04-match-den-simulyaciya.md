# 04: Матч-день — состав, симуляция, результат

**What to build:** Полный матч-день карьеры: экран перед матчем (соперник, состав, скамейка,
рейтинги, Play), симуляция 1:1 с прототипом (голы, ассисты, карточки, травмы, замены, RNG
`seed + fixture_id`), таймлайн-оверлей матча и применение результата. После финального свистка
обновляются таблица, статистика игроков, кондиции и сохраняется карьера; возврат в хаб.

**Blocked by:** 03

**Status:** done

- [x] Matchday-экран повторяет прототип: соперник, свой состав, скамейка, рейтинги, Play/Back.
- [x] Симуляция воспроизводит прототип на одном seed: счёт и события совпадают с golden-эталоном.
- [x] Таймлайн-оверлей показывает события в том же порядке и с теми же подписями, что прототип.
- [x] Результат обновляет результаты фикстур, таблицу, статистику игроков (apps/goals/assists/cards) и кондиции.
- [x] После матча карьера сохранена; повторный вход показывает обновлённый хаб без повторной симуляции.
- [x] Ошибки/пустой состав обрабатываются как в прототипе; headless-тест полного матч-дня.
