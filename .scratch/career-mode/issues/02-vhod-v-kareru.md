# 02: Вход в карьеру — Start / Load / New Career

**What to build:** Рабочий вход в карьеру, как в прототипе: экран старта с Continue/New/Load,
список сейвов, создание карьеры (страна → лига → клуб, имя и национальность тренера) и
сохранение. После создания карьера сразу попадает в свой хаб; Continue открывает последний
совместимый сейв; Load — выбранный. Сейв — JSON-схема прототипа в `user://career/saves/`.

**Blocked by:** 01

**Status:** done (2026-11-09)

**Resolution:** Портированы `Career`/`CareerManager`/`CareerSaveStore` (`scripts/career/`) с JSON-схемой
прототипа и проверкой `version`; сейв прототипа читается без конвертации. `CareerFactory` строит
состав, расписание (двойной round-robin) и снимок клуба/сезона из единой БД через `TeamCatalog`.
Экраны `career_start` / `career_new` / `career_load` на дизайн-системе (UiScreen/UiNav/UiHintsBar,
1920×1080), создание кладёт сейв в `user://career/saves/`. Тайлы Career/Continue в главном меню
включены: Career → старт, Continue → последний совместимый сейв. Промежуточный `career_hub` показывает
снимок и выход в меню (полный хаб — тикет 03). Тесты: `check_career_creation`, `check_career_save_store`,
`check_career_ui`, обновлены `check_main_menu_ui`/`check_main_menu_layout`.
