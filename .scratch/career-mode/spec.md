# Career mode — port spec

Источник: веб-прототип `gf-career-prototype` (Svelte UI + Python/FastAPI логика + `canon.db`).
Цель — перенести режим карьеры в игру, в ветку `feat/career`, в worktree
`open_football_career`.

## Решения

- **Логика — GDScript.** Python-сервер не переносится в рантайм: сезон, симуляция матчей,
  кондиции, контракты, трансферы, входящие офферы, мировой рынок и скаутинг переписываются на
  GDScript 1:1 по `server/career/*`.
- **Один id = tm_id.** Единая БД `open_football.sqlite` собирается dev-инструментом из игровой
  `database.sqlite` и `canon.db`. `id` стран/лиг/клубов/игроков — transfermarkt id (у лиг — код
  вида `MEXA`). Синтетика: страна `International` (id 1), лига `National Teams` (id `NAT`).
  Дубли «клуб + сборная» (3 500 игроков) схлопываются в одну строку игрока.
- **Данные карьеры** (`market_value`, `overall`, `pot`, `birth_date`, `shirt_number`, стадион,
  `tier_rank`, свободные агенты) добавляются в ту же БД; игровые поля (`formation_xml`,
  `tactics_xml`, `kit_url`, `profile_xml`, внешность) сохраняются.
- **Картинки — существующий `UiAssets`** (лица `assets/faces`, гербы/флаги/лого из data-root).
  5 ГБ растровых лиц прототипа не копируются.
- **Сейвы — JSON-схема прототипа** (`version`, `career`-объект) в `user://career/saves/`.
  Сейвы прототипа читаются напрямую; `tm_id` — ключ игрока/клуба.
- **Матчи — симуляция как в прототипе** (RNG `seed + fixture_id`, таймлайн, голы/ассисты/карточки/
  травмы). Подключение 3D-матча GPF — отдельная будущая задача, вне этого порта.
- **UI — экраны прототипа на Godot Control.** 1920×1080, `UiStage`/`UiNav`, клавиатура + геймпад,
  `hover = selected`, вкладки `L1/R1`, нижняя легенда. Визуальная правда — прототип.
- **Тесты — headless GDScript** по сценариям pytest прототипа (golden snapshots по seed/действиям),
  плюс существующие проверки игры остаются зелёными.

## Вне scope

- Онлайн-карьера и синхронизация сейвов между пирами.
- Локализация (UI на английском, как в прототипе).
- Поставка 5 ГБ растровых ассетов прототипа.
- Игра в 3D-движке GPF внутри карьеры (симуляция обязательна, движок — позже).

## Критерий готовности

Полный цикл: создать карьеру → хаб → симулировать матч → управлять составом → трансферы →
скаутинг → конец сезона → следующий сезон. Все экраны совпадают с прототипом по раскладке,
навигации и взаимодействию; Quick Match и сеть не сломаны.
