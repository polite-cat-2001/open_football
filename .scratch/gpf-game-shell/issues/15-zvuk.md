# 15: Звук

**What to build:** Слышны удары по мячу, попадания в штангу, свистки и трибуны. Громкость
регулируется. C++ сообщает события, Godot проигрывает их через свой звуковой движок.

**Blocked by:** 01, 06

**Status:** ready-for-agent

- [ ] C++ отдаёт события удара, штанги, свистка и состояния трибун.
- [ ] Godot проигрывает звуки с учётом громкости и положения.
- [ ] Трибуны реагируют на ход матча.
- [ ] Headless-тест проверяет события.
- [ ] Ручная проверка звука.

> **UI-политика:** если этому тикету нужен UI, портировать соответствующий экран/элемент из
> оригинала (`GameplayFootball-of_port/src/menu/...`) — та же раскладка, подписи, иконки,
> управление и порядок экранов. Godot-UI не изобретать заново; отступления документировать.
