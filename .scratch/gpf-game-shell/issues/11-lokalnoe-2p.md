# 11: Локальное 2P

**What to build:** Два игрока на одном компьютере играют за разные стороны, каждый со своим
устройством. C++ держит двух HumanGamer, ввод одного игрока не влияет на другого.

**Blocked by:** 10

**Status:** in-progress

- [x] Два устройства управляют двумя сторонами.
- [x] Ввод игроков не смешивается.
- [x] C++ держит двух HumanGamer и корректно переключает управляемых игроков.
- [ ] Headless-тест проверяет раздельный ввод и два human id.
- [ ] Ручная проверка двумя игроками (идёт: подсветка и пенальти за away).

**As-built (2026-10-31):** путь 2P уже был собран (два устройства, `parallel` в team
select, два `HumanGamer`), но presentation был одночеловеческий. Исправлено:
- мост отдаёт `get_human_player_ids()` — все human-игроки, а не первого;
- `GpfActors` хранит набор `controlled_ids` и подсвечивает жёлтым **каждого** управляемого;
- `get_snapshot` считает роль/прицел стандарта для человека **бьющей** команды
  (`set_piece_hud_player`), поэтому у away-человека появляется жёлтый прицел пенальти;
  подсказка «S pass / D shot» использует `set_piece_human_taker`.

Осталось: `tests/check_gpf_2p.gd`, меню исполнителя/нырок пенальти для away, повторная
ручная проверка.
