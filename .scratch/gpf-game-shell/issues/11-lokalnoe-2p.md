# 11: Локальное 2P

**What to build:** Два игрока на одном компьютере играют за разные стороны, каждый со своим
устройством. C++ держит двух HumanGamer, ввод одного игрока не влияет на другого.

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] Два устройства управляют двумя сторонами.
- [ ] Ввод игроков не смешивается.
- [ ] C++ держит двух HumanGamer и корректно переключает управляемых игроков.
- [ ] Headless-тест проверяет раздельный ввод.
- [ ] Ручная проверка двумя игроками.
