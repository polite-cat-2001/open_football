# 05: Статы и формация в Godot

**What to build:** Godot считает итоговые статы игроков и позиции/роли формации по формулам
оригинала. Экран состава показывает результат. Матч пока идёт старым путём, поэтому поведение игры
не меняется — проверяется только правильность чисел.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] Формула «база + профиль + возраст» перенесена; тест сверяет результат с эталоном C++ для всех игроков в допуске.
- [ ] Формация парсится и нормализуется как в оригинале; позиции и роли совпадают для выборки команд.
- [ ] Экран состава показывает итоговые статы и позиции.
- [ ] Матч пока использует прежний путь; игровое поведение не меняется.
