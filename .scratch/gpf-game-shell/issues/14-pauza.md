# 14: Пауза

**What to build:** Кнопка паузы замораживает матч и открывает меню. Продолжение возвращает в игру.
Пауза не конфликтует с перерывом между таймами и с видеоповтором гола.

**Blocked by:** 03, 06

**Status:** ready-for-agent

- [ ] Esc или Start замораживает матч.
- [ ] Меню паузы открывается и закрывается.
- [ ] Продолжение возвращает в матч без скачка времени.
- [ ] Пауза не конфликтует с перерывом и повтором.
- [ ] Headless/UI-тест проверяет заморозку и продолжение.
