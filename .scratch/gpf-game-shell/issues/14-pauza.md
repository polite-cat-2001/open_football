# 14: Пауза

**What to build:** Кнопка паузы замораживает матч и открывает меню. Продолжение возвращает в игру.
Пауза не конфликтует с перерывом между таймами и с видеоповтором гола.

**Blocked by:** 03, 06

- [x] Продолжение возвращает в матч без скачка времени.
- [x] Пауза не конфликтует с перерывом и повтором.

(Esc/Enter, game plan, phase menu, D-pad). Оба PASS.
