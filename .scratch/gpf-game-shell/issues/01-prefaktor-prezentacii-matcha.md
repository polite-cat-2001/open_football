# 01: Префактор — разложить презентацию матча на компоненты

**What to build:** Матчевая сцена перестаёт быть одним монолитом. Игра запускается и выглядит
как раньше, но актёры, окружение, повтор, серия пенальти и HUD становятся отдельными частями с
понятными швами. Это подготовка: поведение матча не меняется.

**Blocked by:** None (can start immediately)

**Status:** done

**Resolution:** `gpf_slice.gd` стал тонким оркестратором (связывание + ввод), презентация разложена на `GpfActors` (тела/мяч/подписи/ретикул), `GpfEnvironment` (стадион/газон/свет), `GpfGoalNets` (рамы + C++-сетка), `GpfCameraRig`, `GpfHud` (счёт/фазы/меню исполнителя и перерыва), `GpfReplay`, `GpfShootoutView`; общий lookup материалов — `GpfAssets`. Сцена `gpf_slice.tscn` — те же узлы и базисы. `check_gpf_slice_ui.gd` переведён на публичные поля компонентов. Поведение не менялось; PASS: slice UI, goal net, setpieces, shootout, phase break, match cycle, 90 winner, full match.

- [x] Матч запускается и играется как до изменений.
- [x] Существующие headless-тесты проходят.
- [x] Актёры, окружение, повтор, серия пенальти и HUD можно менять независимо.
- [x] Оркестратор сцены не содержит игровой логики и не дублирует состояние частей.
