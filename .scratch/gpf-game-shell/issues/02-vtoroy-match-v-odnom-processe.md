# 02: C++ — второй матч в одном процессе

**What to build:** C++ умеет остановить текущий матч, создать новый пакет данных и запустить
второй матч без перезапуска игры. Headless-проверка подтверждает, что второй матч живёт с чистым
временем и счётом, а сцена не копит остатки первого матча.

**Blocked by:** None (can start immediately)

**Status:** done (2026-11-01; покрыт тикетом 03)

- [x] Headless-тест: первый матч играет несколько тиков, затем матч останавливается и запускается второй.
- [x] Второй матч начинается с чистого времени, счёта и тика.
- [x] Нет падений и ассертов; повторный останов безопасен.
- [x] Актёры, сетки и динамические объекты первого матча не дублируются во втором.
- [x] Если мешает глобальное состояние, в тикете зафиксирован точный блокер и план его снятия.

**As-built:** `GpfRuntimeNode::stop_match()`/`restart_match()`/`start_match()` умеют второй матч в
одном процессе; `C++`-часть проверяет `tests/check_gpf_rematch.gd` (чистые tick/clock/score,
уникальные id, совпадение количества объектов/сетки, повторный stop и start), сквозной путь
«меню → матч → меню → второй матч» — `tests/check_gpf_game_shell.gd` (та же runtime-нода, свежая
сцена, актёры/сетки/подписи/HUD не дублируются). Оба теста PASS.
