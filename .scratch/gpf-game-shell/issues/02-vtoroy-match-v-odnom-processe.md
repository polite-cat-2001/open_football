# 02: C++ — второй матч в одном процессе

**What to build:** C++ умеет остановить текущий матч, создать новый пакет данных и запустить
второй матч без перезапуска игры. Headless-проверка подтверждает, что второй матч живёт с чистым
временем и счётом, а сцена не копит остатки первого матча.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Headless-тест: первый матч играет несколько тиков, затем матч останавливается и запускается второй.
- [ ] Второй матч начинается с чистого времени, счёта и тика.
- [ ] Нет падений и ассертов; повторный останов безопасен.
- [ ] Актёры, сетки и динамические объекты первого матча не дублируются во втором.
- [ ] Если мешает глобальное состояние, в тикете зафиксирован точный блокер и план его снятия.
