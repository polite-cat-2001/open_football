**Найдено живым аудитом (2026-10-31, скриншоты через MCP):**

1. **Main menu** — ни одна кнопка не имела фокуса: клавиатура и геймпад не работали вообще.
   Исправлено: `Start Match` получает фокус на старте, виден focus-ring, Down/Enter работают.
2. **Prematch** — на входе нет фокуса, все стрелки/Tab игнорировались; `Down` падал на
   `_first_focusable` (`Control.disabled` есть не у всех Control). Исправлено: активная вкладка
   получает фокус, Tab переключает вкладки, поиск контрола проверяет `BaseButton`; у кнопок
   Kick-off явные focus-neighbor (Down → Edit lineups, Right → Start match, Up → вкладка).
3. **HUD** — постоянная debug-строка `GPF slice ... tick ... ball ... actors ...` убрана; статус
   (KICKOFF/GOAL KICK и т.д.) остался первой строкой.
4. **HUD/стандарт** — nameplate исполнителя при камере за спиной раздувался на пол-экрана;
   уменьшен с 64/0.004 до 56/0.0035, но на близкой камере всё ещё крупный.
5. **Team select** — `NationalTeams` без визуального пробела (мелкий дефект шрифта/метрик).
6. **Controller select** — фокуса/курсора нет, но навигация работает; строка help у нижней кромки.
7. **MCP-ограничение:** `runtime_input` с одним keycode не активирует сфокусированную `Button`
   через `ui_accept`; для кнопок использовать `runtime_emit_signal(pressed)`.
8. **Геймпад на главном меню не работал:** в Godot 4.7 дефолтный `ui_accept` **не содержит**
   кнопку геймпада (только Enter/Space), а `ui_cancel` — только Esc. Main menu и контент prematch
   полагались на `ui_accept`. Исправлено: main menu сам ловит A и эмитит `pressed` у фокуса;
   prematch в `_handle_joy_button` активирует `Button`/`OptionButton` по A. D-pad/стик работают
   через `ui_up/down/left/right` (там геймпад есть).
